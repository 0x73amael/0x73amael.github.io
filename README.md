# 0x73amael — Personal Website

A minimal, responsive personal portfolio with a subtle CRT/VHS visual direction. Built with plain HTML, CSS, and JavaScript so it can be deployed directly with GitHub Pages.

## Deploy on GitHub Pages

1. Put the contents of this folder in the root of `0x73amael/0x73amael.github.io`.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://0x73amael.github.io/`.

## Before publishing

- Review the project descriptions and status labels.
- Replace the generic YouTube link in the Maflekat section with the channel URL when ready.
- Add direct repository links to project cards only when those repositories are public.

No build step, package manager, or external font dependency is required.
